# 3.1 月度经营模拟

用户确认实现：每月房价、入住率及营业天数；设施独立收费和成本；按逐月现金结余显示预计首次回本年月。保留年度恒定情景，月度计划显式启用后用于总览与检查。

入口：「收益与回本」内切换「月度经营」，或直接打开 `/web?section=earnings&earningsView=monthly`；「年度简算」保留原四周期恒定测算。「编辑共用收益参数」返回年度页修改每间人数、停用房数、费用预留和投资，「编辑日常运营成本」进入投资页的运营区域。

Project.monthlyPlan 为可选字段，保存格式继续version1。未配置时只展示草案，不写入旧项目，默认未启用；修改有效参数后保存草案，点击「启用月度经营计划」后才用于总览与检查。起始月默认采用北京时间当前月，标为可修改的示例经营日期；连续12个自然月，按真实闰年与月份天数限制营业天数。改变起始月份保留各顺位参数，将营业天数限制到新月上限；起始月可选2000-01至2200-12，跨年派生月份继续连续。预测默认30年，可设1至60年。

每月设置房型价格、入住率、营业天数、其他每日收入及固定支出。点击明细的月份按钮或「编辑月份」下拉框分别设置，亦可将本月参数复制到全部月份，各月天数按实际月长限制，设施逐月利用率不随此操作覆盖。每间人数、停用房数、营业额费用预留比例和初始投资口径沿用年度收益设置；未保存年度设置时仍继承其示例，未填费用需用户补充或明确填0。月度客房收入按可售房数×入住率×单价×营业天数；不同时叠加恒定年度收入。

设施收益绑定场地中的非客房设施，可设置收费单位、每天可售总单位、每月利用率、单价、直接单位成本及每月固定成本。默认无收费项目；用户添加后初始价格与成本保留待填写。收费量=每天容量×当月利用率×本月营业天数，收入与直接成本按收费量算。利用率0时不收费，固定费仍保留；不计入的项完全停计。未绑定或已删除设施不产生幽灵收入，应提示并可移除。复制场地设施不自动复制收费项目。

其他每日收入只录未在独立设施中列出的收入；设施直接成本只录未含在日常费用中的部分，避免重复。收入与成本以即期现金近似，不建应收/应付款或融资时间表。所有未知价保留null，0需要明确填写。

复用原运营成本：guest/staff/person/room/day基数按营业天数计，period/manual固定费用按自然月天数÷原运营天数均摊，停业月固定工资、水电等仍计。额外固定月费按当月填写金额，营业额预留按总收入×所填比例。此拆分是本软件情景约定。

逐月累计经营现金，首次达到选定初始投入即记录预计回本年月；年数按此前整月数＋当月剩余本金÷当月正现金插值，再除12，明确假设当月均匀收支。即使全年结余不为正，也先检查是否在前期达到本金；之后仍可能回落，曲线继续展示。未填经营成本不得给确定回本；所选预测期内未达到仅表示情景范围未回收。建设本金未包含完整费用时显示暂估，不阻止已补齐经营成本的现金结余计算。循环重复这12个月参数，按未来自然月重算天数，闰年变化时营业天数取当月上限。收入与费用分项按分舍入，累计采用每月已舍入结余，不另用恒定年数计算替代。原运营、设施和年度参数不被模拟改写。

页面、总览、CSV、离线报告与方案检查复用 `estimateMonthlyPlan`。`financialProjection.ts` 在月度启用后为总览及检查选择月度结果，显示首12月合计，年度恒定情景可继续查看，月度启用状态明确。月度页「导出月度测算」和导出菜单「月度经营计划 (.csv)」包含逐月经营参数、设施收费与来源、首12月经营明细及完整预测期的现金回收清单；已保存月度设置时，原收益CSV追加该清单，HTML报告另列月度段，不要求先保存年度收益设置。保存、导入、复制、重载均保留月度设置；导入切换沿用3.0先提交旧输入的保护。
