# 拍卖厅

2026-10-03，2.6 版新增。入口为「场地设计 → 更多设施」，搜索「拍卖」或「拍卖厅」，也可在「餐饮与社交」分类中找到；选择后点击「添加到方案」。原「棋牌休闲」筛选仍展示六种室内休闲空间，不包含拍卖厅。

预设标识为 `auction-hall`，归类为「餐饮与社交」，沿用 `restaurant` 配套建筑类型。默认尺寸 30 × 20 米、1 层、客房数 0，参考单价为 5600 元/平方米，是可修改的内部示例假设。面积和预算按配套建筑规则计算，支持精确面积核算、分项价格与总包报价；不计入客房数、网球场数量或绿地面积。

2D 与轴测 3D 展示拍卖台、展品台、拍卖槌和四排竞拍席，随设施尺寸、旋转与楼层显示。席位图案仅为示意，未建立实际容量模型。软件用于空间规划，不提供实际拍卖交易功能。

设施支持调整尺寸与位置、旋转、复制、删除、锁定与隐藏，并复用自动保存、JSON 导入导出和方案报告。JSON `version` 仍为 `1`，新增预设标识随方案保存；升级不重置已有方案。
