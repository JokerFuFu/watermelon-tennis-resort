# 因数探险家

打开 [因数探险家](http://127.0.0.1:5173/factors)，或双击项目目录中的 `启动因数游戏.command`。游戏复用项目的本机服务，网址仅在运行服务的同一台电脑上可访问。页面独立于酒店设计工作台和游戏大厅。

## 顺序闯关

主线从 1 开始，完成当前关后才能进入下一个整数，直到 100000。每关的空格数等于该数字的正因数数量，包含 1 和数字本身；数字 1 只有一个空格，填 1 即可。所有正因数各填一次，顺序不限。例如数字 6 可填 `6、1、3、2`。

点击「检查答案」提交。空白、非正整数、重复或不能整除目标数字的答案会标出，修改后可再次检查，不扣金币或钻石。全部正确后立即结算奖励，每关只领取一次，重复提交或刷新不会重复发放。主线末关完成后保留营地和随机挑战，不再提供下一关。

## 奖励

主线每关金币为 `10 + 2 × 正因数数量`，钻石为 1。数字是 10 的倍数时额外获得 2 钻石，即第 10、20、30……关共获得 3 钻石。例如第 6 关有 4 个正因数，奖励 18 金币、1 钻石。

随机挑战金币为对应主线金币的 75% 向下取整，至少 8 金币；钻石固定为 1，不享受主线每十关的额外钻石。使用双倍金币券后当前关金币翻倍，钻石不变。

## 道具商店与背包

购买只扣除对应货币并增加背包数量，回到关卡后点击背包中的道具才会使用。余额不足不能购买；没有可用目标、当前关已完成或双倍加成已激活时，不会消耗不适用的道具。

| 道具 | 价格 | 使用效果 |
| --- | --- | --- |
| 单格提示 | 10 金币 | 填入一个缺失的正因数，提示格锁定。优先填空格，没有空格时替换未锁定的错误或重复格，保留已正确填写的因数。 |
| 配对提示（背包显示「因数配对」） | 20 金币 | 补上乘积等于目标数字的一对因数；已填对其中一项时只补另一项，平方根只填一格。提示格锁定。 |
| 随机挑战券 | 30 金币 | 开启独立随机挑战，保留主线数字、已填答案和进度。已有未完成随机挑战时继续原挑战，不再消耗券。 |
| 双倍金币券 | 3 钻石 | 在当前未通关的主线关或随机关激活，当前关金币奖励翻倍；同一关只能激活一次，下一新关重新计算。 |

提示只补答案，仍需点击「检查答案」领取奖励。

## 随机挑战

随机目标范围为 2 至 `min(100000, max(20, 当前主线数字 × 5))`，填写和检查规则与主线相同。完成挑战不会增加主线已通关数量，也不会跳过主线关卡。

未完成挑战可点击「暂存挑战，回到主线」，之后通过背包下方的「继续数字……的随机挑战」返回；已填答案、提示和双倍金币状态保留。完成后可「回到主线」，再次使用挑战券才开启新的挑战。

## 退出与自动保存

点击「退出到营地」保留已填答案、已通关数量、金币、钻石、背包和随机挑战。未通关时继续冒险仍是当前关；主线已通关后退出会先准备下一关（末关除外），随机挑战已通关后退出会切回主线。关闭网页由玩家自行操作。

游戏自动保存到当前浏览器的本地存储，键名为 `factor-quest-save-v1`，与酒店、荒岛求生及其他小游戏存档独立。重新打开同一浏览器、同一来源地址可恢复；来源地址包括协议、主机和端口，换浏览器、改用 `localhost` 或更改端口会使用另一份存储。清除网站数据会清除进度。

页面底部显示保存状态。如果显示「自动保存不可用，请保持页面打开」，本次修改可能无法在关闭后恢复。损坏旧存档会尝试保留备份并开启新游戏，页面会显示备份是否成功。

## 专项验收

在项目目录运行规则与存档测试：

```sh
npm run test:factors
```

先启动本机服务，再运行独立浏览器验收，默认访问 `http://127.0.0.1:5173/factors`：

```sh
npm run test:factors:browser
```

浏览器脚本使用独立会话，结果与桌面、手机截图写入 `test-results/`。
