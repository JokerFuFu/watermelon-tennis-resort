# 面积统计口径

2026-10-03。采用现有设施、独立建材及自建组合的矩形边界和 0° / 90° 朝向统计面积，计算中保留小数，展示保留两位平方米。属于方案几何计算，真实场地面积仍以测量结果为准；不提供 CAD / BIM 测绘或法规审查认证。

总用地为宽 × 深。界内总占地对所有设施、独立建材和自建组合的外包投影裁切到用地后求并集；同一块地只计一次。未配置面积为总用地减界内总占地，不能自动视为道路或绿地。

2.8 版的「建材与作品界内投影」单独统计建材与组合的界内投影并集；组合采用整体外包矩形，包括零件之间的空隙，不再逐件重复计入同一组合。材料 Z 高度和正常叠放不增加平面用地，也不计作设施相交。自建物不自动增加建筑基底、建筑各层面积、客房或球场数量。自动排布将材料投影作为固定障碍，仅移动未锁定设施。

建筑基底对酒店和建筑类配套的界内占地去重。建筑各层面积依然按每栋完整占地 × 楼层累加，平面重叠和越界不能悄悄扣掉楼面或改变预算工程量；保留布局警告。

界内可用绿地为明确配置绿地与天然活动草坪的并集，扣除非绿地设施、建材和组合外包投影覆盖。绿地之间相交只计一次，隐藏和锁定设施及建材仍参与物理占地及绿地遮挡。

界内重叠区域指被至少两个设施覆盖的地方，每处重叠区域只计一次，包括三重覆盖；建材与组合不参与此设施重叠指标。界外占地按设施、独立建材和组合外包矩形的联合并集在用地外的区域统计，不重复计算。完整设施占地合计（不去重）仍仅累加设施，另列为工程量口径，不能拿它直接推算实际空地。

设施面积明细另列完整占地、界内占地、界外面积和建筑各层面积；明细界内占地是每设施独立计算，不能直接加总当作去重占地。CSV 总计采用同一空间计算入口，另列建材与作品投影的 X / Y、外包宽深。

在「方案总览」的「面积核算」查看汇总，展开「查看设施面积明细」查看每项占地；此处与「场地设计」的「场地信息」均提供「导出面积明细」，文件名为项目名称加 `-面积明细.csv`。面积列保留两位小数，并附计算口径与显示、锁定状态。用地与设施尺寸、设施位置支持 0.01 米步进；客房配置 CSV 的面积列同样保留两位小数。

验收：小数尺寸、两重/三重覆盖、边接触、完全及部分越界、90°旋转裁切、绿地重叠与非绿地遮挡、隐藏和锁定设施、空场地、200设施稳定计算、建材组合外包去重、叠放与楼面不变量、费用不变量、保存重载、CSV与网页一致和手机布局。

`npm test` 包含面积计算及面积 CSV 单元测试；先运行 `npm run dev`，再在另一终端运行 `npm run test:area`，执行独立浏览器会话的面积专项验收。
