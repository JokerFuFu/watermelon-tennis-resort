# 酒店设计 4.2

在「场地设计」中一次选中多个设施，再整体移动、排列或管理。原酒店方案、建材和20张荒岛游戏地图保留。

## 选择和操作

打开「设施列表」，逐项勾选，或用「选择全部结果」加入当前搜索与分类的匹配设施。已选项跨分类保留；点击「编辑选区」进入批量面板。画布上按住 Shift 点击可增加或取消一项；普通点击已选成员保留选区，可以拖动整体移动。点击空白或「清空选择」取消选区，点未选设施则改为单选。

两项以上显示批量面板。方向按钮可选择每次1、5、10米；也可填写横向、纵向位移后点击「应用位移」。整体移动使用相同位移，边界处限制整组选区，保留相对间距；选区整体尺寸超过用地时拒绝移动。面板显示所选设施的界内去重占地、客房合计和包含设施间隔的选区宽深，选区范围不等于实际占地。

「左边对齐」「水平居中」「右边对齐」「上边对齐」「垂直居中」「下边对齐」沿当前选区范围对齐。「横向均匀排列」「纵向均匀排列」至少选择3项，保持首尾位置并调整中间设施的净间距；空间不足、需要负间距时不修改位置。对齐可能产生设施重叠，仍可在「场地信息」查看提醒。

## 管理和保护

- 任一已选设施锁定时，整组移动、对齐排列及删除均停止；可先「全部解锁」。选区含隐藏项时，画布拖动停止，但未锁定的选区可在面板用数字移动。隐藏仍计入面积、客房和预算。
- 「复制选区」保留设施尺寸、房型和报价，副本显示且未锁定；最多200个设施，超限时整次复制停止。月度经营收费不随设施复制，副本收费需另行设置。
- 「删除选区」同步移除这些设施的月度收费项。一次成功的批量操作可用一次撤销恢复，删除撤销同时恢复设施和收费项。

选区是临时选择，不写入方案文件。设施变更沿用自动保存、JSON导入导出和撤销重做；JSON版本仍为1。建材的作品组合仍在建材工作台操作，荒岛游戏仍使用独立存档。

## 验收方法

几何逻辑位于 `src/facilitySelection.ts`，批量面板位于 `src/FacilityBatchPanel.tsx`，列表和画布分别位于 `src/FacilityManager.tsx`、`src/SiteCanvas.tsx`。`src/facilitySelection.test.ts` 随 `npm test` 执行。开发服务运行后，用以下命令在独立浏览器会话检查选择、拖动、排列、边界保护、撤销、月度收费、保存重载和手机布局：

```sh
npm run test:design
```

脚本入口为 `scripts/verify-hotel-design-42.mjs`，默认访问 `http://127.0.0.1:5173/web`，可用 `COURTSIDE_URL` 指定服务地址，结果写入 `test-results/`。实际是否通过，以当次命令输出和退出码为准。
