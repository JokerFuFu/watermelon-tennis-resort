# COURTSIDE 网球酒店设计工作台

2026-10-02。用户要求开发用于设计网球酒店的软件。在空目录中交付可本地运行的中文浏览器应用，默认聚焦概念场地布局，可继续调整用户具体项目需求。

## 设计与范围

白色工作台、森林绿操作重点、红土球场。持续展示场地模型与项目参数。默认示例为“青屿网球度假酒店”，界面不宣称真实地理地址或真实工程造价。所有价格为可修改的示例单价，工程施工及规范审查不在本版范围。

交互：2D/轴测3D视图、选择和拖动设施、位置尺寸及楼层/客房/单价编辑、增删复制旋转、撤销重做、缩放、保存和恢复、JSON导入导出、SVG布局导出、客房配置、投资明细、项目创建及模板切换。

## 实现顺序

1. React / TypeScript / Vite，领域模型独立；启动无需后端账号。
2. 独立开发模型、估算和验证；独立绘制可交互SVG场景；主代理实现完整工作台。
3. 用同一Project连接表单、场景与指标，历史按操作记录，拖动结束提交一次。
4. 浏览器本地保存，在导入前严格校验，失败保留原方案。提示重叠与超出用地边界。
5. 领域计算测试、生产构建、浏览器功能和视觉验证；检查保存后reload与导出内容。

## 验收

打开本地地址可用；添加与编辑设施立即更新图与指标；撤销恢复数据；保存刷新仍保留；导出的JSON可导入；错误导入不会覆盖项目；2D和3D对应同一布局；宽窄屏无全页横向溢出；说明和启动方式齐备。
