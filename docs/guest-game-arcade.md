# 西瓜顾客游戏大厅 · 6.0

入口：`/play?game=lobby`。原 `/play` 继续进入荒岛求生，通过其「游戏大厅」按钮切换；管理端入口为 `/web?section=play&game=lobby`。游戏名称写在 `game` 参数中，刷新及浏览器后退、前进均恢复对应页面。

| 类别 | 游戏 | 玩法 |
| --- | --- | --- |
| 方格益智 | 数独、扫雷、2048、数字华容道、翻灯 | 单人操作，悔一步及重新开始 |
| 棋类 | 五子棋、中国象棋、围棋、国际象棋、黑白棋、井字棋 | 同屏轮流对弈，可用基础电脑走一步 |
| 牌类 | 斗地主、掼蛋 | 单人加基础电脑，选择手牌、提示、出牌和不出 |
| 牌类 | Klondike 纸牌接龙 | 单人，点击源牌与目标牌列或基础堆 |
| 探索 | 荒岛求生 | 保留20地图及原三存档槽 |

每款游戏的页面均有玩法说明。数独题面具有唯一解，三档难度、笔记与三次提示；扫雷提供9×9和16×16，首格及周围无雷，右键或触屏插旗模式；2048同一次滑动不重复合并，达到2048可继续。数字华容道由合法滑动洗牌，翻灯由可解开关组合生成。

棋类是休闲本地对局。五子棋采用自由规则，不设竞技禁手。中国象棋实现基本走法、将军及将死/困毙，连续追将的竞赛裁定由双方约定。围棋采用简单劫、气与提子、两次连续停手终局；双方共同标记整块死子后确认休闲区域数子，白贴7.5。死子标记与确认结果保存到该游戏存档，可重载查看；未确认的数子为暂计。国际象棋实现易位、吃过路兵、升变、将死、逼和及50回合和三次重复，极少见死局由双方约定。基础电脑用于辅助休闲，没有声称专业棋力。

斗地主有地主与农民阵营、底牌、常见单/对/三带/顺子/连对/飞机/四带二/炸弹/火箭。掼蛋使用两副牌、对家搭档、级牌、红心级牌百搭、顺子、连对、钢板、炸弹、同花顺和四王；本版为完整休闲单副牌，可选择新局级牌，不进行连续升级或进贡赛事。电脑只根据自己的手牌与公开出牌选择合法动作，人类出牌后推进电脑回合，悔一轮恢复该次人机轮。纸牌接龙采用翻一张、可回收牌库、红黑交替降序牌列、同花色A至K基础堆，四堆完成获胜。

规则参考：[FIDE 国际象棋规则](https://handbook.fide.com/chapter/E012023)、[边锋开发商的斗地主飞机说明](https://www.gameabc.com/news/201906/5425.html)、[中国企业体育协会掼蛋赛事规则说明](https://www.cesa.org.cn/xhxm/gdjbs/Content_5123.shtml)。页面具体休闲差异以上述说明为准，不称正式赛事认证。

## 存档与数据保护

新游戏仅使用自己的 `courtside-arcade-{game}-v1` 键，文件含版本1、游戏标识、保存时间及棋盘/牌局状态。与酒店方案和求生钱包、地图、三个存档槽均分开。进度自动保存，也可点击保存、导出或导入；不同游戏文件不能交叉导入，非法棋盘、篡改牌池、伪造终局及超过1MB文件均拒绝。

损坏原文受保护，不自动覆盖，可以下载原始存档。重新开始或明确导入前先备份旧档，并回读验证；备份失败时保留当前进度。另一页面已经更新同一游戏时，自动保存拒绝覆盖，明确保存先备份另一版本。浏览器禁止存储时提示并允许当前页面游玩与导出。撤销历史留在当前页面，重新载入后从已保存局面继续。

## 验证

`npm test` 包含独立规则与存档黄金测试。`npm run test:arcade` 使用独立浏览器测试15入口、14款新游戏实际操作、胜局、存档重载、数据隔离、备份失败、围棋确认、电脑回合与手机布局。原求生、地图、启动恢复、工作台和酒店扩展另有回归脚本。实际结果以当次日志和退出码为准；构建用 `npm run build`。
