# 酒店设计工作台 4.2

目标：把单个设施的摆放扩展为多个设施一起编辑，便于排列客房、球场及配套区域。

实现分工：`facilitySelection.ts` 负责选区包围盒、共同位移和对齐几何；`SiteCanvas.tsx` 负责多选及本地拖动预览；`FacilityBatchPanel.tsx`、设施列表和 App 负责批量动作。临时选区不写入方案，JSON 版本仍为 1。

- 列表逐项勾选、选择当前搜索结果和清空；画布 Shift 点击添加或取消，普通点击已选项保留组以便拖动，点击空白取消选择。
- 两项以上显示批量面板，含去重占地、选区宽深、客房数量。整组拖动和方向键使用共同位移，边界限制不能破坏相对间距；任意已选锁定项阻止整组几何操作及删除。
- 六种边缘/中心对齐及两个方向的均匀净间距排列；排列至少三项，空间不足提示且保持原位置。每次成功动作只生成一次撤销记录。
- 批量复制保留属性、房型和报价，副本未锁定且显示；最多 200 设施，超限整体拒绝。复制只处理设施，月度收费绑定不复制。批量删除同步清理这些设施的月度收费。
- 显示/隐藏与锁定/解锁可批量操作。隐藏设施仍计入面积和预算。原有建材、月度经营和荒岛存档保持独立。
- 验收：几何单测；实际 2D/3D 多选拖动、对齐/分布、边界、锁定、撤销、复制、删除收费清理、保存重载、手机布局；再复验原工作台与月度经营及启动路径。

实施顺序：先完成几何模块与测试，同时完成指针交互；接入列表与批量属性面板；构建并跑专项验收；独立审查后同步说明与版本号。
