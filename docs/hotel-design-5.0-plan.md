# 酒店设计 5.0 快速搭建

本次更新围绕在原酒店方案中快速增加完整功能区，继续保留 JSON 版本 1、原设施与建材、收益配置及独立游戏存档。

- 八套功能区：网球训练、庭院住宿、家庭亲子、康体休养、餐饮社交、棋牌娱乐、商务拍卖、度假后勤。设施来自现有库，先展示清单、布局、新增客房、去重占地、建筑面积及设施工程估算，再点击加入。报价口径沿用现有示例与用户配置。
- 阵列复制：新增 1–10 行、每行 1–10 份选区，原件保留。设置横纵净间距，保持每份内部坐标差、旋转、房型和费用；新增副本显示且未锁定，月度收费另设。
- 追加策略：原设施（含锁定、隐藏）与材料组作为固定障碍，寻找完整区块空位。200 设施上限和无空位均整体拒绝，预览和取消不写入方案。既有布局可以有提醒，但不能因此被移动或重置。
- 适应选区：仅显式操作相机，2D 与 3D 均包含全部可见选中项及楼高；不改变尺寸、位置、可见状态和保存数据。
- 更新说明：界面提供版本更新入口，清楚列出 5.0、4.2、4.1 的实际功能。

实现：独立 hotelExpansion.ts 与几何单测；独立 HotelExpansionDialog 与响应式样式；相机命令通过 SiteCanvas 可选参数；App 提交最新输入、核验预览来源未变化，再一次追加并可一次撤销。

验收：八套组合、不同大小与旋转的阵列、材料和隐藏障碍、上限与无法放置、输入校验、预览取消不变、应用与撤销、旧房型及报价/月度收费保持、2D/3D 选区居中、保存导入重载，以及电脑和手机布局。再复验 4.2 设计及月度、建材、启动路径。
