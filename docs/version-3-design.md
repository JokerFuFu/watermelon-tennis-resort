# 3.0 全工作台优化

本轮在2.9的酒店、设施、建材、运营及收益基础上完善操作链路。保留现有方案数据及version1保存格式，未报价继续保留未知。

1. 五个主页面分别使用 `section=design`、`section=rooms`、`section=budget`、`section=earnings` 和 `section=overview` 参数，导航通过 `pushState` 更新地址，`popstate` 恢复浏览器前后历史；刷新保持对应页面，旧地址默认场地设计。总览可跳转设计、投资及收益。
2. 收益页直接编辑原运营项的单价与计入状态，保留原天数、数量、基数、税和来源。启用运营预算仍是独立操作。增加当前入住率上下10个百分点的临时对比，不覆盖保存参数。
3. 总览增加建设已计投资、年收入、年现金结余与回本摘要；仅已保存收益设置时将经营缺项、非正现金结余或未填初始投资加入方案检查并可定位收益页。继续区分未填写、示例预览和完整情景。页面、CSV与报告的入住率情景共用 `getEarningsScenarios`，结果不覆盖原配置。
4. 修复1100px桌面保存/全屏按钮超出边缘，以及在建材上使用移动工具/中键时误打开编辑的问题。
5. 缓存与项目无关的重复计算，减少建材拖动时全库重绘；收益页和建材工作台按需加载。数字输入保留原范围限制及整数策略，增加无效或修正提示，切换材料同步属性。导出和保存提交输入后读取最新有效方案快照。导入或切换项目前先提交原方案输入，切换后的导航不再提交旧字段；复制及另存也从提交后的最新快照生成，避免旧输入覆盖新方案。
6. 验收范围为五页面、51设施、33建材、场地面积、报价、运营、收益、保存重载、JSON/CSV/报告和390px手机；新增交互由 `npm run test:v3` 验证，各专项仍使用独立浏览器会话。依赖不进行无目标升级，版本号表示本软件更新，不宣称帧率或全部第三方依赖最新。
