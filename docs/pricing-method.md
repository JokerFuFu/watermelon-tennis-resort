# 预算精细化

2026-10-03。保留原有示例单价与用户已填价格，增加分项工程量、供应商总报价、税口径、情景范围和缺项识别。2.6 版设施库增至 51 类，六种室内休闲空间及新增拍卖厅按配套建筑计价，单价仍为可修改的内部示例假设。公开资料不够核定全部设施，因此不得宣称“北京实时报价”或准确率。

分项草案从原综合金额拆分，保留基线。建筑按土建/装修/机电/家具设备，球场按基础/面层/围网/照明，泳池及户外设施按土建/面层/设备。家具可按客房间数、围网按周长、设备按手填数量；随后尺寸/间数改变会更新相应工程量。

所有草案标记内部假设，区间仅为规划情景范围。用户可改各项价格与来源，或者输入总包报价（供应商、日期、范围、税口径）。不含税且税率缺失时标出未核算税费；不默认套用税率。

项目预算分设施工程、设计监理、预备费，以及土地、场地工程、市政接入和开办费用。未录入额外费用不计入已计合计，并明确列为缺项。默认3%设计、1%监理、10%预备费是可调整规划假设，非官方收费标准；建设性质和档次记录工程口径，不自动给整项目乘系数。

2.8 版另列可选的建材采购预算，材料单价初始为未报价，明确填0按零计入。按件、最长边米数、最大两边乘积的板面面积或宽×深×高的外包体积计算数量；轴向交换和旋转不会重复增加采购量。空心材料、砂石堆及卷材的外包尺寸不代表净体积、重量、展开量或损耗。建材采购默认不计入建设合计，避免重复既有土建综合价；启用 `materialBudgetIncluded` 后，将已知采购金额单独加到建设的低、中、高情景合计，不追加设计、监理或预备费，也不改变设施工程金额和原报价覆盖率。未报价与税口径待核实项在启用后进入建设缺项提示；采购清单始终保留预览。未含税且税率明确时只加一次税，税口径或税率未知时保留缺项，不填入假定税率。预算 CSV、建材 CSV、离线报告和对比沿用同一采购计算入口；材料来源与包含范围可编辑，用户录入未经独立核验。规格与操作见 [建材区说明](material-builder-design.md)。

2.7 版另增可选的餐饮与日常运营消耗预算。旧方案未含 `operating` 时只预览内部示例，用户启用后才保存并计入。饮用水、宾客餐食、员工餐和客房用品分别按总人天、宾客人天、员工人天与入住房晚计算；人数、入住率和期间均为可修改假设。工资、水电燃气按所选期间总额录入，初始未报价；空白未计入，明确0按零计入，禁用项不纳入金额或缺项。运营费用不参与建设设计、监理或预备费，综合已计合计是建设加已启用的所选期间运营消耗；情景范围只调整建设部分，不表示全部经营或生命周期成本。预算 CSV、离线报告、对比与检查同步纳入已启用运营数据，示例采购单价不是北京市场报价。计算及来源口径见 [日常运营预算说明](operating-budget-design.md)。

2.9 版「收益与回本」复用上述建设已计金额作为初始投资，包含已选择另计的建材采购，不使用建设加所选期间运营合计；也可手填完整初始投入。日常运营费用按收益页的可售客房、入住率与人数重新换算，期间固定费用按原天数均摊，保留原运营设置。经营结余不重复扣建设投入，静态回本采用初始投资除以年度经营现金结余。口径与经营缺项处理见 [收益与回本说明](earnings-method.md)。

3.0 版收益页可快捷编辑原运营项的单价和计入状态，保留原用量、期间、人数、税与来源，运营启用状态单独控制；临时入住率情景重新换算经营消耗，不改建设本金或原保存配置。方案总览的财务摘要复用建设与收益计算，未填写费用继续列为缺项。保存与导出在提交输入后读取最新有效方案快照，不以先前页面快照替代已提交报价。

3.1 版月度经营复用相同建设本金口径，按真实自然月拆分运营现金。人天、房晚、营业天等变动耗用按当月营业天数计，原期间总费与手填固定费用按自然月天数/原运营期间均摊，停业月仍计固定成本。设施独立收费按每日可售总量×逐月利用率×营业天数计收入与直接耗用，另计设施固定月成本；不计入的收费项停计全部收入和成本。初始收费价与成本留空，用户明确填0才按零；其他每日收入、额外固定支出与设施直接成本须排除已在原日常运营费用或设施收费里计入的部分。此功能不把现金结余当会计净利润，不将建设投入重复列为经营成本。首次累计结余达到投入时显示预计年月，建设缺项使投资回收标为暂估，经营缺项阻止完整结余和确定回本。总览和检查仅在月度计划启用后采用该口径；详见 [月度经营说明](monthly-plan-design.md)。

旧 JSON 无 pricing/budget 时继续原算法；只有用户启用分项或录入报价才改变设施价格。旧方案不自动添加 `materials`、`materialAssemblies` 或 `materialBudgetIncluded`，打开建材区不启用采购计费。各视图、导出、对比使用同一计算入口；已锁定设施不接受价格改动，建材或组合含锁定零件时不接受材料价格编辑。供应商报价为用户录入、未独立核验。大于90天报价提醒复核而不宣称法律意义过期。
