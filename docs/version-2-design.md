# 西瓜网球度假酒店工作台整体升级

2026-10-03。以现有 32 类设施和用户保存的方案为基础，升级管理、编辑、排布和保存体验。

- 管理：可搜索的设施列表；选中与定位；锁定及显示开关。隐藏只影响模型显示，仍参与场地检查与统计。
- 编辑：点击拖动直接选中；锁定设施不可移动或修改；1 米网格吸附；指针位置缩放；最高 1600% 放大；定位设施自动聚焦；适应画布保留当前 2D/3D 模式。
- 排布：纯函数生成新方案，保留名称、尺寸、房型、价格和锁定设施。间距 4 米、边界留空 6 米；无法全部放下则保留原方案。预览后由用户点击应用，操作可撤销。
- 保存：另存为新方案；保存前合并其他标签页的最新方案库；同方案的外部更新在未编辑时同步，有本地未保存内容时保留并提示冲突；保留损坏原始存储的现有保护。
- 兼容：版本 1 方案继续可导入；locked、visible 均为可选布尔字段，无字段时默认未锁定、显示。
- 验证：旧测试回归；新字段与排布单元测试；编辑锁定、隐藏、定位、自动排布确认/撤销、备份、跨页同步和手机显示的浏览器验证。
