# 饮用水、餐食及日常用品预算

2026-10-03。新增独立运营消耗预算，默认口径为酒店采购与消耗成本，用户未确认售价收入模型。建设已计金额及其设计、监理、预备费原算法保持；综合已计资金需求 = 建设合计 + 已启用的所选期间运营费用。

旧项目没有 `operating` 时不自动写入运营假设。预算页提供示例预览和「启用并计入运营预算」，启用后按当前项目计算并自动保存；费用随所选数量基数、用量和单价调整。按整个期间录入的总额不自动随人数或天数改变。缺项用 null 表示，明确0可计入，禁用项不纳入合计或缺项。运营费用不参与建设设计、监理或预备费，停用保留原有配置并停止计入综合合计。

默认草案为30天、70%假设入住率、每间2位宾客、员工0人；既可按客房推算平均宾客，也可手填平均每日服务人数。手填人数替代宾客推算，不与推算数相加；入住房晚仍独立按总客房 × 假设入住率 × 天数计算。平均人数及平均入住间数可为小数，属于计划平均值，不能宣称实际客流预测。

每项量纲：guestDay=宾客人天、staffDay=员工人天、personDay=宾客和员工总人天、roomDay=入住房晚、day=期间天数、period=1个期间、manual=手填总数量。总数量=对应基数×用量，manual不再乘天数或人数。金额=总数量×单价，已填未税税率时加税一次；未知税率单列待确认，不自动猜税率。含税单价的内含税额未拆分。

初始内部示例：饮用水每人每天2瓶×2元、早餐1餐×20元、午餐1餐×35元、晚餐1餐×35元、茶饮1份×3元、水果零食1份×10元；前三餐及茶饮零食仅宾客人天，员工餐单列staffDay，避免重复计餐。洗漱用品每入住房晚1套×8元、布草洗涤1次×6元、清洁耗材1套×3元。员工餐每天2餐×20元；员工工资、水电燃气按期间总额录入、初始未知，不按员工人天自动推算工资。全部示例可修改，不是北京市场报价或完整经营成本。可以增删自定义项，列表最多30项；租赁、维护、保险等未录支出仍需按实际范围补充。

运营单价可标注内部假设、参考资料或用户录入报价，并填写来源名称、日期、采购范围和可选链接。用户录入报价未经独立核验，报价来源必须填写日期。初始示例税口径为待确认；未税且已填税率时加税一次，已含税金额直接计入，不自动猜税率。综合情景范围只调整建设部分，运营采用当期已录用量和单价，不另生成市场价格区间。

持久化可选 `Project.operating`，JSON仍version1，严格白名单与数值、日期、来源校验。预算CSV、离线报告、方案对比及检查中心同时纳入已启用运营费用；原建设测试标记与 `ProjectEstimate.total` 保持建设口径，运营及综合有独立标记。保存、导入、另存、撤销、重载保持原有保护。

验收：人数/期间/房晚与手填数量分别计算、员工不重复计餐、null与0及禁用、税加一次、费用不改变建设预备费、旧JSON不注入新字段、严格无效导入拒绝、UI数字/CSV/HTML一致、未失焦导出、保存与真实reload/JSONroundtrip、手机布局及原建设回归。
