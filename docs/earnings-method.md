# 收益与回本测算

2026-10-03。新增独立「收益与回本」页面，Web 与手机都能查看，桌面可通过 `/web?section=earnings` 直接进入并在刷新后保持该入口。3.1 版在页内提供「年度简算」「月度经营」，月度入口为 `/web?section=earnings&earningsView=monthly`。按已规划的酒店房型计算可售客房，允许扣除停用间数，设置房型每晚价格、入住率、每间人数、额外每日收入、额外月支出以及按营业额预留的税费/平台费用。

初始房价为内部情景示例：标准间500元、景观房700元、套房1000元，均可调整，不代表北京实时市场价。入住率和每间人数先沿用已有运营设置。额外每日收入初始为0，额外月支出与营业额费用预留比例初始留空，须填写实际金额或明确填0。收益设置作为 Project.earnings 可选字段保存，JSON版本仍为1；打开页面不写入旧项目，修改有效参数后才保存收益设置。

年度简算收入＝各房型可售间数×入住率×每房每晚价格，再加用户填写的额外收入。周期为日1天、周7天、平均月365/12天、年365天，未舍入值按平均月换算；各收入和费用分项按分舍入，平均月乘12与年合计可能有少量舍入差额，回本采用全年直接测算值。该模式假设全年营业，入住率及单价恒定，不引入季节或增长率。

日常费用复用已有运营费用项；按本页可售客房、入住率和人数计算人天/房晚，员工人数沿用原运营设置。原运营页的手填宾客人数不直接沿用到收益测算，收益页始终按可售客房推算宾客人数。期间固定费用与手填总量按原 operating.days 均摊，再换算目标周期；不把30天工资当成一天或每个周期相同的金额。测算仅生成临时数据，不修改原运营设置，不把建设加期间运营合计当回本本金。

3.0 版在「年度经营成本来源」提供单价和计入状态的快捷编辑，修改保存回原运营费用项，并保留原天数、用量、计量基数、员工人数、税口径和来源；编辑单价不自动启用运营预算。可单独启用或停用运营预算，通过「编辑日常运营成本」跳转投资页的运营区域修改数量、税率、来源等高级配置。

经营现金结余＝收入－日常运营成本－额外支出－营业额费用预留；不是会计净利润。空价保留未知，明确填0按零。停用房数超过库存、运营预算未启用、在用房型房价或额外收入未填、已启用且用量大于0的运营费用单价未知，或额外月支出及营业额费用预留比例未填时，完整结余和回本年限待补齐，另列已填范围数字供核对。不计入的运营项及用量为0的项不列为未知成本。税口径、示例假设和建设缺项继续提示。

回本使用建设已计投资（含已选择另计的建材采购），也可手填完整初始投资。年度简算在正年度现金结余下，静态回本年数＝初始投资/年度现金结余；结余≤0时无有限回本，投资未填或为0时提示填写。建设投资仍缺土地等金额时，按已计投资的年限标为暂估，建设缺项不阻止经营现金结余计算；选择手填完整投资时以该金额为本金。年度简算累计现金回收图最多展示40年，超过范围的回本年限仍显示在结果中。该模式忽略资金时间价值、融资、折旧以及现金流逐年变化，不代表已兑现收益。

3.1 版月度经营为连续12个自然月分别设置房价、入住率、营业天数、其他每日收入和额外固定支出。起始月份默认采用北京时间当前月的示例，允许修改，营业天数按真实月份和闰年限制；改变起始月份保留各顺位参数，并将营业天数限制到新月份上限。每间人数、停用房数、营业额费用预留比例和投资口径仍共用年度收益设置，不叠加年度恒定收入。旧项目仅预览未启用草案，修改有效参数后保存 `Project.monthlyPlan`，点击「启用月度经营计划」后才用于总览与方案检查，JSON版本仍为1。

月度计划可为场地中的非客房设施设置独立收费：每天可售总量×该月利用率×营业天数为收费量，乘收费单价为收入，乘直接单位成本并加固定月费为独立成本。每个设施最多一项收费，初始收费价与成本留空；利用率或营业天数为0时无收费和直接耗用，固定成本仍计，取消计入则该项全部停计。删除场地设施同时移除绑定收费，复制单个设施不自动添加收费；导入的无效绑定列缺项并产生零收入，不能形成幽灵收益。其他收入及直接成本只填写现有设施收费与日常成本未包含的部分。

月度日常费用按原计量基数拆分：人天、房晚和营业天消耗按当月营业天数换算，原期间总费和手填用量按自然月天数/原 `operating.days` 均摊；停业不免除固定费用。额外固定支出按每月填写金额计，营业额预留按总收入乘共用比例计。空价不作为0，经营缺项仍阻止完整结余和确定回本；未完整的建设本金只把回本标为暂估。累计每月经营现金首次达到投入时记录年月，随后可能再次跌回投入以下。预测默认30年，可设1至60年，按未来真实日历循环12月参数；范围内未回收不表示永久无法回本，年数仅按达到投入当月均匀收支近似。操作和计算界限见 [月度经营说明](monthly-plan-design.md)。

3.0 版增加当前入住率、低10个百分点和高10个百分点的临时情景，限制在0%至100%。其余房价、收入、成本及投资配置沿用当前方案，每个情景重新计算客房及宾客消耗；不保存对比情景，也不替换原运营或收益参数。方案总览复用相同计算显示建设已计投资、年收入、年经营现金结余和回本摘要，缺项保留为待补齐。已保存收益设置的方案检查可定位收益缺项、非正现金结余和未填初始投资。

导出菜单和收益页均提供收益测算CSV，包含四个周期金额、经营假设、原运营费用设置、投资口径与缺项，3.0 版同时导出入住率情景。离线方案报告仅在收益设置已保存时显示年度测算表及情景，未保存时提示填写；年度页面、CSV 和报告共用 `getEarningsScenarios`。3.1 版月度页及导出菜单另提供月度CSV，包含逐月参数、设施收费来源、首12月明细和完整预测期；原收益CSV在月度设置已保存时追加该数据。报告在 `monthlyPlan` 已保存时另列月度段，即使尚未保存年度收益设置也显示，共用未填参数继续列缺项。月度页面、总览、检查、CSV 和报告共用 `estimateMonthlyPlan`，`financialProjection.ts` 根据启用状态选择总览和检查的计算模式，导出不修改源方案。

计算定义参考：[联合国旅游统计编制指南](https://millenniumindicators.un.org/wiki/spaces/IRTSCG/pages/5311061/B.2.1.%2BProviders%2Bof%2Bmarket%2Baccommodation%2Bservices%2Bclassified%2Bunder%2BAccommodation%2BISIC%2Bdivision%2B55)、[Eurostat 住宿统计口径](https://ec.europa.eu/eurostat/cache/metadata/en/tour_occ_esms.htm)。收入公式由入住率和平均房价定义推导。静态现金回收方法参考：[ACCA](https://www.accaglobal.com/gb/en/student/exam-support-resources/foundation-level-study-resources/ffm/ffm-technical-articles/discounted-payback.html)、[OpenStax 会计教材](https://openstax.org/books/principles-managerial-accounting/pages/11-2-evaluate-the-payback-and-accounting-rate-of-return-in-capital-investment-decisions)。周期和费用均摊方式是本软件的测算约定。
