# 建材区与自建作品

2026-10-03，2.8 版。保留现有51设施与运营预算，增加独立建材实体和组合，不把一块砖当作酒店设施。在「场地设计」底部点击「建材区」，或在「投资估算」的建材采购面板打开工作台；桌面并排显示库、近景和属性，手机通过四个页签切换区域。

提供32种常用建材加自定义构件：砖块/砌块/混凝土板，木板/木方/胶合板，工字梁/角钢/槽钢/方管/圆管/钢筋，玻璃/石膏/纤维水泥/岩棉/挤塑板，瓦片/彩钢板/瓷砖/透水砖，水管/弯头/防水卷/水泥袋/砂堆/碎石堆/涂料桶/螺栓，以及门板/窗框。以商品常见形态绘制，尺寸均可编辑，不能宣称穷尽世界上所有建材。

`MaterialPiece` 独立存 `id/materialId/name/x/y/z/width/depth/height/rotation/color/locked/visible/priceBasis/unitPrice/taxMode/taxRate/evidence`，`unitPrice` 可为 `null`。最多500件；真实小尺寸砖在专门的建材近景工作台编辑，不改变总场地尺寸。支持XY拖动、Z属性和叠放、0/90旋转、立放与侧立（尺寸轴交换）、复制、删除、撤销及保存。`axisOrder` 保留尺寸轴交换后的商品形态方向，平面和立体图共用同一图形组件；库内规格以毫米显示，属性以米编辑。

`MaterialAssembly` 独立记录 `id/name/pieceIds`，一个零件只能归属一个组合；组合至少2件，最多250个组合。Shift点击材料或勾选列表可多选，再输入作品名称并组合。组合移动保持相对位置与高度；组合内任意材料锁定则拒绝整组移动、旋转、复制、删除或解散，属性编辑也先解锁。复制组合创建全部新ID；选择组合成员执行删除会删除整个组合，底层同时清理不足2件的组合。支持解散重新编辑，解散保留材料。

场地显示和报告都呈现材料，排序考虑平面与高度。总占地统计设施、独立材料和组合的联合外包矩形投影；组合按整体外包范围占地，包括零件间空隙，组合成员不重复计入。`materialArea` 单独记录界内建材与作品投影并集。叠放正常，不触发设施相交警告，也不自动变成建筑基底、楼面、客房或球场；投影会遮挡已配置绿地。隐藏与锁定材料仍计入统计。自动排布避让建材及组合，不移动它们。

3.0 版修复场地建材上的移动工具与中键手势：平移不会误打开工作台，选择工具点击仍打开编辑。建材工作台按需加载，库内33个预览缓存，拖动不重新生成整个库；采购计算按方案变化更新。数字属性保留既有范围限制，并显示无效输入和提交后的修正提示，切换材料时同步新的属性值。

建材采购单列；按件、最长边米、最大两边乘积的板面平方米或外包体积立方米计算数量。体积是模型外包量，不是空心材料净用料、散料实际体积或结构重量，也不自动计算施工损耗。价格默认未报价，0明确零；用户可填来源、包含范围及税率。默认不额外计入已有设施建设预算，避免与土建综合价重复；勾选「单列加入建设预算」后将已知采购额加入建设低、中、高情景合计，不再追加现有设计、监理、建设预备费。未含税且税率明确时加税一次，含税不再加税，未知口径或税率保留提示。未报价与税口径待核实项仅在启用采购计费后纳入建设缺项；采购清单保留预览。与运营费用总计仍按所选期间相加。

`Project` 可选 `materials/materialAssemblies/materialBudgetIncluded`，JSON仍version1，严格导入校验且旧项目不注入新字段。导出菜单提供「建材清单 (.csv)」，列出坐标、规格、方向、计量数量、单价、已知金额、组合、状态、来源与范围。面积CSV列投影，投资CSV单列采购计费状态与金额，方案对比列已纳入采购。离线报告显示全部材料（含已隐藏材料）与自建组合，不改写当前项目的可见状态；保存和JSON导入导出保留材料与采购配置。当前功能用于示意拼搭与采购数量估算，不提供施工或结构验算。
